Este repositório concentra a proposta para a NewPack, seguindo a lógica já usada no Programa Corporativo de Inovação com IA do Grupo HP, mas com um avanço importante: aqui o workshop inicial já é desenhado como porta de entrada para um projeto posterior de implantação de agentes.

## Tese

A NewPack não precisa apenas de uma capacitação genérica em IA. Pelo contexto levantado, há dores maduras em orçamento, obras, suprimentos, controladoria, RH e comunicação interna.

A proposta recomendada é unir:

1. **Workshop inicial de 6 horas** para nivelar entendimento, reduzir resistência, levantar gargalos e demonstrar agentes na prática.
2. **Projeto de implantação de agentes por 3 meses** para estruturar ambiente, canais, permissões, primeiros fluxos, skills e integrações com acompanhamento do time de Paulo Jardim.

## Arquitetura conceitual

A proposta será construída sobre a lógica do **Sistema Operacional Invisível**:

- humanos;
- agentes;
- ferramentas e sistemas;
- base de conhecimento / segundo cérebro;
- comunicação interna estruturada;
- governança de permissões e aprendizados.

O objetivo é transformar conhecimento tácito dos sócios e líderes em ativo operacional replicável para o time.

## Próxima etapa

Depois da validação textual deste escopo, o próximo passo é gerar o HTML executivo com identidade visual no padrão Paulo Jardim + SeuTimeIA e publicar via GitHub Pages.
